Universal Live Chat - Kisi bhi website pe lagao, Phone pe Popup pao

Visitor kahi bhi chat karega, tere phone pe instant notification + sound + vibration. Ollama AI auto-reply jab tu offline ho.

📋 Step 1: Copy Embed Code

<script src="https://finalphasessolution-hub.github.io/Saini/jaspal-ollama-chat.js" data-model="llama3.2" data-phone="919958037734" data-bridge="http://localhost:3000/api/chat"></script>

Kisi bhi site ke <head> ya <body> end me paste kar do.

🤖 Step 2: Ollama Setup (Tere PC pe)

set OLLAMA_ORIGINS=* ollama serve # Dusri CMD me: ollama pull llama3.2 # ya jo model hai: ollama list

Bridge server ke liye niche server-bridge.js dekho - CORS 100% fix.

📱 Step 3: Phone pe Popup Enable Karo

  1. Is page ko phone me khol: chat-admin.html
  2. Add to Home Screen karo
  3. Enable Phone Popups button dabao - Notification permission allow karo
  4. Test Popup button se check karo - sound + vibration ayega
